# DeepSeek Harness Mobile v1.1.0

## What's changed

- Added Chinese, English, and System language preferences across the native UI, notifications, accessibility labels, connection validation, and error states.
- Added a persistent server connection list so previously verified Harness addresses can be selected without retyping them.
- Added the Web-matched command-button transition: the lower-left plus rotates into a close control while the command menu is open and returns when it closes.
- Added first-run DeepSeek credential onboarding using Harness provider, settings, and credential metadata. Writable credentials can be saved in the app; read-only or restricted configurations show an explicit Harness Web recovery path.
- Distinguished a forbidden `settings.describe` request from a general authentication failure, avoiding an incorrect Cloudflare sign-in loop when only privileged settings are unavailable.
- Added model-catalog partial-failure rows with provider details and a retry action, while keeping successfully loaded models usable.
- Added the final-assistant action strip with clipboard copy confirmation, positive/negative feedback, branch-at-message, turn runtime, time to first token, and token-rate metrics.
- Added compare-and-set feedback reconciliation so concurrent feedback updates do not silently overwrite newer server state.
- Preserved the reader's scroll position while reviewing older messages and followed the bottom only when already nearby or after an explicit new prompt.
- Added bilingual prompt submission recovery, terminal-turn errors, retry activity, and max-token activity states.
- Expanded the README with live agent progress, context and to-do views, background task notifications, and ColorOS Fluid Cloud examples.

## Compatibility

- No private or project-specific server address is embedded in the app or these notes.
- The app connects only to a Harness server configured by the user.
- Android 8.0 (API 26) or newer is required.
