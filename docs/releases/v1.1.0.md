# DeepSeek Harness Mobile v1.1.0

## 更新内容 / What's Changed

### 中英文界面与连接管理 / Bilingual Interface and Connection Management

新增中文、English 和跟随系统三种语言选项，覆盖原生界面、系统通知、无障碍标签、连接验证和错误提示。服务器连接页现在会保存已成功验证的 Harness 地址，之后可以直接从连接列表切换，无需重复输入。

Added Chinese, English, and System language options across the native interface, system notifications, accessibility labels, connection validation, and error messages. Successfully verified Harness addresses are now saved and can be selected from the connection list without retyping them.

命令菜单的交互也与 Harness Web 对齐：左下角的加号在菜单展开时旋转为关闭按钮，关闭菜单后再恢复为加号。

The command menu interaction now matches Harness Web: the lower-left plus rotates into a close control while the menu is open and returns to a plus when the menu closes.

### API Key 配置引导 / API Key Setup

当应用检测到 DeepSeek 官方模型缺少凭据时，可以直接在 Android 客户端填写并保存 API Key。如果 Harness 设置为只读，或当前连接无权修改设置，应用会明确提示用户前往 Harness Web 完成配置。

When credentials for the official DeepSeek model are missing, the API key can be entered and saved directly in the Android client. If Harness settings are read-only or the current connection cannot modify them, the app provides a clear recovery path through Harness Web.

应用现在会区分 `settings.describe` 权限不足与一般身份验证失败，避免只有高级设置不可访问时错误地跳转到 Cloudflare 登录流程。

The app now distinguishes a forbidden `settings.describe` request from a general authentication failure, preventing an incorrect Cloudflare sign-in flow when only privileged settings are unavailable.

### 模型加载与错误恢复 / Model Loading and Error Recovery

模型选择器会显示部分模型供应商的加载失败原因和重试操作，同时保留已经成功加载的模型，不会因为单个供应商异常而让整个模型列表失效。

The model picker now shows partial provider failures with details and a retry action while keeping successfully loaded models available, so one provider error no longer disables the entire catalog.

补充了消息发送失败后的输入恢复、终止回合错误、自动重试活动和达到最大 Token 限制等状态，让失败原因和下一步操作更清楚。

Prompt restoration after submission failures, terminal turn errors, retry activity, and max-token states are now represented explicitly, making failures and recovery paths easier to understand.

### 助手消息操作栏 / Assistant Message Action Strip

助手完成回复后，最后一条消息下方会显示复制、点赞、点踩和从该消息创建会话分支等操作，同时展示任务运行时间、首字延迟（TTFT）和 Token 生成速度。

After an assistant response is completed, the final message shows controls for copying, positive or negative feedback, and branching into a new conversation. It also displays total runtime, time to first token (TTFT), and token generation speed.

消息反馈使用带版本检查的更新机制。如果其他客户端已经提交了更新，Android 客户端会重新同步最新状态，不会静默覆盖服务器上的新反馈。

Message feedback uses version-aware updates. If another client has already submitted a newer change, the Android client reconciles with the latest server state instead of silently overwriting it.

### 阅读与滚动体验 / Reading and Scrolling

用户向上查看旧消息时，界面会保留当前阅读位置；只有已经接近底部或明确发送新消息时才自动跟随最新内容。窄屏设备上的消息操作栏保持单行，并支持横向滚动。

When reviewing older messages, the app preserves the current reading position. It follows new content only when already near the bottom or after an explicit new prompt. On narrow screens, the message action strip remains on one line and supports horizontal scrolling.

### 项目展示 / Project Showcase

README 新增了 Agent 实时执行过程、上下文与待办事项、后台任务通知，以及 ColorOS 流体云胶囊态和展开态的实机展示。

The README now showcases live Agent execution, context and to-do views, background task notifications, and real-device ColorOS Fluid Cloud capsule and expanded states.

## 验证情况 / Verification

全部 41 项 Debug 单元测试通过，没有失败、错误或跳过；Android Release Lint、R8 压缩和资源收缩均成功完成。

All 41 Debug unit tests passed with no failures, errors, or skipped tests. Android Release lint, R8 minification, and resource shrinking completed successfully.

签名后的 v1.1.0 Release APK 已在 Pixel 10 上通过 `adb install -r` 覆盖安装验证，原有应用数据得到保留。安装后的版本为 `1.1.0`（version code `6`），可以正常启动进入 `MainActivity`，启动后的日志窗口中未发现对应的 `AndroidRuntime` 致命异常。

The signed v1.1.0 Release APK was installed as an update on Pixel 10 with `adb install -r`, preserving existing app data. The installed package reported version `1.1.0` (version code `6`), launched into `MainActivity`, and produced no matching fatal `AndroidRuntime` exception in the post-launch log window.

APK Signature Scheme v2 验证通过，签名证书与 v1.0.4 一致。源码与公开截图检查未发现 API Key、Bearer Token 或仓库凭据；一张包含私有局域网地址的 QA 截图已主动排除，没有进入公开提交。

APK Signature Scheme v2 verification passed, and the signing certificate matches v1.0.4. Source and public screenshot scans found no API key, bearer token, or repository credential. A QA screenshot containing a private LAN address was intentionally excluded from the public commit.

## 兼容性 / Compatibility

应用和发布说明没有内置任何私有或项目专用服务器地址，只会连接用户自行配置的 Harness 服务器。

The app and release notes contain no embedded private or project-specific server address. The app connects only to a Harness server configured by the user.

需要 Android 8.0（API 26）或更高版本。

Android 8.0 (API 26) or newer is required.
