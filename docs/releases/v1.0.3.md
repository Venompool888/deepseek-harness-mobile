# DeepSeek Harness Mobile v1.0.3

## What's changed

- Replaced the unsupported attachment picker with the same Commands menu used by Harness Web.
- Added the Web command actions for `compact`, `export`, `feedback`, `goal`, `permission`, `plan`, and `model`.
- Removed the custom `Default` and `Queue` composer chips that are not present in Harness Web, and kept Commands pinned at the lower-left edge on narrow phones.
- Added session export through the official `/api/session.export` endpoint, downloading the session log as a ZIP archive.
- Routed permission, plan, and model commands to their native mobile pickers; commands that require text input are inserted into the composer for editing.
- Rebuilt the Full access warning as a dark Harness Web-style modal instead of a native Android alert.
- Matched the Web warning copy, icon, checkbox acknowledgement, disabled/enabled primary action, close button, cancel action, and outside-tap dismissal.

## Compatibility

- No private or project-specific server address is embedded in the app or these notes.
- The app continues to connect to a user-configured Harness server.
- File upload remains unavailable because the current Harness Web interface does not expose that feature.
