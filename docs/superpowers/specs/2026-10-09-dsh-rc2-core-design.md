# Android 原生客户端适配 dsh 0.2.0-rc.2

状态：设计方向与书面规格已获用户批准，实施计划待审阅。日期：2026-10-09。

## 目标与分工

用户选择第一轮优先连接与核心聊天适配。目标是保留 Android 原生客户端，让手机可靠连接 dsh 0.2.0-rc.2 Web Host，读取和切换会话、选择模型和预设、发送和停止消息、查看实时任务状态并响应审批。

Codex 负责协议、状态管理、集成和验收。前端交互设计由 agy 交付，原生 Codex 子代理负责调用和观察 agy。对接子代理遵循用户最新规则，使用 GPT-6/6.1 家族模型。本阶段 agy 只交付设计文件，不修改产品源码；规格批准后再依计划实现界面。

## 范围

1. 连接与认证：普通服务器地址、带 token 的启动链接、已保存连接切换、认证失效提示。保留现有 Cloudflare Access 连接路径，分别管理外层 Access 与 Harness 自身认证，不将二者视为替代关系。
2. 核心请求：会话和工作区列表、创建和切换会话、历史页读取、模型和 Agent 预设、权限和已有命令入口、消息排队/发送/停止。
3. 实时状态：Host 会话控制流、所选会话历史跟随与助手增量、重连快照修复、运行/完成/失败状态、已有待办与上下文展示。
4. 审批：等待、提交中、允许一次、拒绝、被其他客户端处理、取消和过期。优先实现审批；原生问答与计划审阅不在本轮。
5. 后台通知：同步迁移现有 TaskMonitorService 使用的会话读取和运行状态，防止前台适配后后台仍访问旧接口。

本轮不增加插件管理、终端、完整文件浏览器、自动化任务、附件上传、目标编辑或子代理树。高级功能继续走现有 Web 入口。旧 Harness 协议不承诺兼容；目标 Host 缺失必要能力时明确提示版本不兼容。保留现有 Views 架构和品牌设计，不迁移 Compose。

## 连接设计

- 从输入中解析服务器地址与可选启动 token；仅接受本轮支持的根路径和单个非空 token 参数，不默默吞掉其他参数。
- token 兑换前校验目标地址；维持现有公网 HTTPS 与私网 HTTP 约束。
- 启动 token 只用于根页面 Cookie 兑换，不作为 Cloudflare Bearer Token，不拼入业务 RPC、WebSocket 或日志。
- 保存干净服务器地址；认证 Cookie 按服务 authority 隔离，允许进程重启后复用仍有效的 Cookie。
- 同一服务器的 HTTP RPC、实时 WebSocket、导出与 Web 入口保持认证一致。限制认证重定向，不向未知 authority 转发凭据。
- 连接验证执行真实但无副作用的必需读取请求。HTTP 401、权限拒绝、路由缺失和网络不可达分别给出可理解的提示。
- 本机 127.0.0.1 是电脑地址；模拟器可使用 adb 端口反向映射。真机通过明确配置的局域网或 HTTPS 服务连接；不会自动更改服务器监听范围或开启公网入口。

## 协议与状态边界

- 将请求编码、响应验证、认证、逻辑流生命周期从 MainActivity 的界面逻辑中隔离；沿用现有数据模型中仍适用的部分。
- 逐个对照官方 Remote 声明确认命名空间、方法、具名参数和返回类型；不能只把点替换为斜线。
- 响应验证信封类型、rpcId、成功/失败结果与错误码，保留可显示的业务错误，避免将所有拒绝误报为登录失败。
- 一个物理 Remote mux 承载不同逻辑流，分别管理打开、数据、结束、取消和错误。先建立 Host 控制流，再按所选会话打开跟随流及必要的 Remote 事件流。
- 初次与重连快照替换本地状态；后续按游标/序号与助手流 revision 处理增量。丢失基线或发现断档时重新同步，避免重复拼接输出。
- 会话切换和服务器切换取消旧逻辑流，并通过连接代次阻止晚到回调污染新界面。前台和后台监听各有明确生命周期。
- 正常流式更新直接更新会话状态；周期读取只作为有限恢复手段，不能作为新协议实时流的替代。
- 发送失败保留输入；网络结果不明确时先同步服务器状态，不自动重复发送。停止和审批也必须处理重复/过期响应。

## 前端交付约定

agy 提供连接输入、验证/认证反馈、顶部连接状态、实时消息/任务状态、审批区域和重连体验的设计。覆盖中文/英文、明暗主题、紧凑屏幕、大字体、键盘弹出及屏幕阅读器描述。

保留原生 Views 和现有 Material 3 主题。设计以状态及交互规则为主，提供可审阅的本地 HTML 示意或等价可视文件。展示不得包含真实启动 token、凭据或私人会话内容。

Codex 向界面提供以下概念状态：连接阶段与错误类别、会话身份与运行状态、当前消息窗口和增量、可用模型/预设/权限、待审批身份及提交结果、输入草稿及发送状态。界面设计不定义或猜测底层 RPC 字段。

## 验收

1. 单元层：启动链接解析、认证 Cookie 隔离、RPC 相关性和错误分类、Remote 帧生命周期、快照与增量合并、断档、会话切换晚到回调、审批失效和重复响应。
2. 本机 rc.2 集成：无副作用列表与历史读取；单独测试会话中创建、发送、停止和切换模型/预设；验证 HTTP 与 WebSocket 认证一致。
3. 断线恢复：服务或连接中断后重新同步，不丢完整历史、不重复回复、不将另一会话事件显示到当前会话。
4. 审批：专用测试任务中的允许一次/拒绝、另一客户端处理和取消场景。
5. Android：Debug 构建、相关单元测试、Release lint；可用设备上验证连接、聊天、键盘、滚动、前后台任务通知及基础可访问性。

只读探查不发送提示或改变用户已有会话。实施后的真实发送/审批验证使用明确的专用测试会话。真机或特定事件无法复现时报告未验证范围，不以构建通过替代集成验收。

- 新协议范围比旧接口修补大，按认证、单次请求、逻辑流、界面整合依次实施，分阶段验证。
